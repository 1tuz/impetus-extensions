# Hello Extension

This package demonstrates the portable `instruction_pack` path.

It has no executable and requests no permissions. The skill is activated by the Impetus Extension Host from the package-local `skills` directory.

Use this package as the minimal reference before choosing MCP or `host_process` for capabilities that require executable code.
